Sheet 01, About

How I got here

I got into machine learning by refusing to trust it. Before I'd use a library function, I wanted to know what it was actually doing underneath, so I wrote backpropagation by hand in NumPy just to watch the gradients move. That habit never really left. I still want to see the gears turning before I let a system run on its own.

Most of my recent work sits at the point where a language model stops being a chatbot and starts being infrastructure: connecting Claude to a real database through the Model Context Protocol, building retrieval and tool calling workflows, and adding the kind of validation that keeps a good demo from becoming a bad incident. I care about clean architecture just as much as I care about the model working, because one without the other rarely ships.

I'm currently finishing my Bachelor's in Computer Science at the University of Central Punjab in Lahore, on a full merit scholarship. Outside of coursework, I've spent a good deal of time as a teaching assistant explaining polymorphism to sophomores, and as a founding member of our university's IEEE Robotics and Automation Society chapter, helping get it off the ground.

IMDb MCP Server
June 2026

An MCP server that lets Claude query a live movie database using plain English instead of SQL. I used FastMCP to expose the tools, Pydantic v2 to validate every input, and a guard that restricts the model to read only SELECT statements, so a stray prompt can't accidentally write to the database. It's the clearest example I have of prompt engineered tool design meeting real world caution.

SHEET 03.2 OF 6
Neural Machine Translation from Scratch
2026

An encoder-decoder translation model built with nothing but NumPy: manual forward propagation, an attention mechanism with explicit alignment weights, and backpropagation through time written out by hand instead of left to autograd. I built it to answer questions frameworks usually hide, like how a sentence gets compressed into a vector and why attention exists to fix that bottleneck. It's the closest thing I have to a from-scratch look at what an LLM's building blocks are actually doing.

PythonNumPy Attention MechanismsSequence Models
Repository
