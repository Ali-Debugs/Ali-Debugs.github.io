Sheet 01, About

How I got here

I got into machine learning by refusing to trust it. Before I'd use a library function, I wanted to know what it was actually doing underneath, so I wrote backpropagation by hand in NumPy just to watch the gradients move. That habit never really left. I still want to see the gears turning before I let a system run on its own.

My final-year project made that mindset practical. I owned five Python intelligence and automation modules spanning forecasting, tariff calculation, OCR, browser automation, recommendations, and a grounded AI advisor, then integrated them with a teammate-built web platform. The work taught me to think in interfaces and failure modes, not just features.

I graduated with a Bachelor's in Computer Science from the University of Central Punjab in Lahore, with a 3.93/4.00 CGPA and a 100% merit scholarship. As an OOP teaching assistant, I mentored more than 30 students through code reviews and debugging; as an IEEE Robotics and Automation Society founding member, I helped organize technical events and workshops.

Sheet 03, Project set

Selected work

SHEET 03.1 OF 3
SEBPS — Smart Electricity Bill Prediction & Advisory System
Collaborative final-year project

A modular platform that turns electricity bills, 12-month LESCO history, live meter readings, appliance usage, and tariff rules into forecasts and practical guidance. I owned five Python intelligence and automation modules: multi-model forecasting with LOOCV/MAE selection and confidence-weighted blending; tariff-aware billing; OpenCV and OCR extraction; Playwright and BeautifulSoup history collection; appliance and budget recommendations; and a Groq-powered advisor. I integrated those modules with a teammate-built Django REST, React, TimescaleDB, and Docker platform, with retries, confidence scores, diagnostics, and graceful failure paths.

SHEET 03.2 OF 3
Movie Recommendation System
Content-based machine learning

An interpretable recommender built on the TMDB 5000 dataset. I combined overview, genre, and keyword features; transformed them with TF-IDF; ranked related titles using cosine similarity; and precomputed the top six recommendations per movie into JSON. A React 18 and Vite client consumes the static results directly, keeping the deployed experience fast and removing the need for a runtime backend.

PythonPandas Scikit-learnTF-IDF Cosine SimilarityReact / Vite
SHEET 03.3 OF 3
Binary Classification of Diabetes — ANN from Scratch
First-principles implementation

A 9-4-1 binary classifier implemented without TensorFlow or PyTorch. I wrote forward propagation, sigmoid activation, backpropagation, and gradient descent in NumPy; prepared eight BRFSS 2015 health features with a bias term; and trained for 300 epochs at a 0.1 learning rate while monitoring MSE and accuracy. The project made the network's data flow and learning behavior visible instead of hiding them behind a framework.

PythonNumPy PandasMatplotlib Backpropagation
